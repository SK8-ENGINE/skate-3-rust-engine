# Block Zombie Shooter

Enable the mod from Escape > Mods. The skater carries a small block pistol.
Press controller RB or keyboard F to fire in the direction the skater faces.
Zombies are non-physical block targets that approach the player. Press R to restart.

The gun is a local visual attached to the displayed RIGHTHAND bone. Zombie movement,
hits, health, score and waves are Lua-owned arcade rules; they do not alter native
Skate collision, ragdoll, scoring or animation state.
